# Terraria Web

Play your own copy of Terraria (via tModLoader) in the browser, with friends.
The site contains no game files: each player picks their own install folder and it is loaded locally.

Status: early (see `docs/design.md`). Notes: `DECISIONS.md`, `NEEDS_REVIEW.md`.

Based on [fna-wasm-threads](https://github.com/r58Playz/fna-wasm-threads) (MIT) and
[FNA](https://github.com/FNA-XNA/FNA) (Ms-PL).
